# Scope: free community tool

Decided 2026-08-14. This supersedes the Definition of Done in
[the production implementation plan](../plans/2026-08-03-production-implementation-plan.md)
for everything below. That plan was written for a formal product release; this is a free,
low-budget cyber-hygiene tool for Romanian public institutions.

**The plan is not deleted and not rewritten.** It records what was decided in August and
why, and a plan edited to match a later decision stops being evidence of anything. This
file records what changed instead.

## Dropped

| Item | Why |
| --- | --- |
| Independent penetration test | Not affordable at this scope. The consequence is stated plainly in the README rather than papered over: every security claim here is thorough self-assessment, not independent verification. |
| Signed release artifacts / provenance | Removed from `make release-check` rather than left failing. A gate demanding an attestation nobody intends to produce is a permanent red, and a permanent red teaches people to stop reading the report. |
| Release-candidate process | No formal release, so no tag gated on approvals that are no longer being sought. |
| Counsel, privacy and licensing review as launch blockers | No longer gate shipping. The obligations they were about have not gone away; what changed is that they are no longer a prerequisite for a free tool nobody is charged for. |

## Paused

| Item | State |
| --- | --- |
| Agent gateway (Milestone 6) | Parked. It was never wired: `siembiot_agent` is imported by nothing, `agent_analysis` returns a constant, and `SIEMBIOT_MODEL_PROVIDER` — which was read nowhere — has been deleted so it stops reading as a switch. Restarting means writing a provider *and* connecting the step; the contracts and 70 adversarial tests are intact and waiting. |
| Public Observatory, heavy path | Moderation queue, corrections, takedowns and consent workflow presuppose a legal process that no longer exists. The code stays; nothing drives it. |
| Public score page | Not now. If it returns, scope it separately and lighter: opt-in, band and date only, never findings, one-click withdrawal. |

## Kept, deliberately

- **Container and IaC scanning**, non-blocking. It costs nothing and its first real run found a PyJWT authentication-bypass CVE.
- **The `infrastructure` gate** in `make check`, blocking. No scanner, no network, so it cannot silently stop running.
- **The `.trivyignore` expiry gate.** Still the only mechanism here that trips on a date.
- **The FastAPI/Starlette upgrade**, scheduled before 2026-11-12.

## Hard rules that survive the rescope

These are not defaults. They were decided on the merits and do not relax because the
scope got smaller.

1. **Reputation is not hygiene.** `E.domain_reputation_clean` resolves to `warning`,
   never `fail`, and stays in its own pillar. An institution configured well that got
   compromised must not score the same as one configured badly that has not been caught
   yet — that difference is the only thing a hygiene score is for.
2. **OTX indicators are private-report-only, permanently.** Never a public page, never an
   opt-in publication, whatever is decided about publishing scores. Publishing "this town
   hall appears in threat intelligence" on community-contributed evidence that can be
   wrong is the sharpest risk in this product, and sharper than anything the dropped
   penetration test would have found. Enforced in data: the check is classed
   `private_only` and the publication projector filters on it.
3. **An unconfigured provider never reports a clean result.** No key means the check says
   it does not know, not that the domain is fine.
