# Security Policy

SIEMBIOT is in design phase and has no supported release yet.

Do not report suspected vulnerabilities in public issues. Until a dedicated security mailbox and encryption key are published, contact the repository owner privately. The first release candidate must add a monitored `security.txt`, response targets, safe-harbor language reviewed by counsel, and an incident triage runbook.

Never include credentials, personal data, private findings, raw provider payloads, or authorization manifests in reports. If a secret is committed, revoke it first; deleting it from the current branch is not sufficient remediation.

The product is restricted to passive public observation or explicitly authorized, tightly constrained checks. Exploitation, brute force, password testing, denial of service, stealth, unrestricted scanning, and out-of-scope connections are prohibited.
